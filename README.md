# 細胞探索室：物質進出細胞的方式

本地七頁學習網站。以「物質進出細胞的方式_多頁學習架構規格書_v1.0.md」為內容及行為契約，「提示詞彙整v1.pdf」提供視覺與一般互動方向。使用 React、Vinext（Next.js 相容路由）、Tailwind CSS 與既有 Shadcn/Base UI 元件。

## 本地開啟

在 Finder 雙擊 `start-local.command`，或於本目錄執行 `./start-local.command`，保留終端機視窗。瀏覽器開啟 http://localhost:3000/ （若埠已使用，以終端機顯示網址為準）。目前驗收使用的伺服器已啟動。

不需登入。資料僅保存於瀏覽器 localStorage；不同瀏覽器、裝置或網址不會同步。清除網站資料會刪除該瀏覽器紀錄。本專案沒有對外部署。

## 已開放內容

- 七頁依序解鎖的引導課程，加上隨時開放的第 08 頁成果上傳。
- 三態與擴散使用指定的 PhET 內嵌模擬；各有三題觀察任務。濃淡與滲透、細胞反應保留原有操作。
- Q01–Q06 形成性練習、Q08–Q13 六題整合評量、Q14 三卡選做遊戲。
- 圖像放大、逐列回饋、提示、示範後再練、首次答案、修正與最高分。
- 每題首次答對 2 分，第二次起答對 1 分；多列題全對才算答對，僅看解析完成為 0 分。完成頁面不另送分。學習積分上限 24（6 題原有練習與 6 題新觀察），評量 12 分、遊戲 6 分，三者分開。
- 重新整理保留草稿、模型條件、觀察、提示、首次答案與已完成紀錄。

高濃度細胞分支與 Q07 依規格暫緩，不提供答案、不扣分。七頁完成只能稱「目前開放內容完成」，不能稱完整教材已掌握。

## 驗收路線

1. 第一頁在 PhET 觀察固態、液態、氣態，提交三題觀察及 Q01，應完成本頁。
2. 第二頁分別選只加水、只加色素、只減水，先預測再顯示；每次從同一基準開始。
3. 第三頁在 PhET 依序設定藍／紅粒子 60／20、20／60、40／40，先預測再移除分隔器，提交觀察題。兩色等數不代表已分布均勻。
4. 第四頁水必須選兩條路徑；漏選、多選都會記為該列待修正。
5. 第五頁完成三種濃度條件，再切換兩種讀法；相同條件下箭頭不反向。
6. 第六頁完成兩類細胞 × 兩種溶液；濃食鹽水顯示待確認。
7. 第七頁六題都提交後才顯示回饋。原題修正不更新首次與最高分；新一輪完成才更新最高分。
8. 切換頁面、重新整理、反覆提交與重設模型，應不重複給分。

已進行 TypeScript、建置及模型單元測試。尚未進行真實 iPad 觸控、旋轉或瀏覽器端到端操作驗收。

支援瀏覽器若提供實驗性的 document.modelContext，會註冊讀取學習進度與導覽頁面工具；不支援不影響學習。此環境未提供支援該 API 的驗證上下文，未宣稱已驗證 WebMCP。
